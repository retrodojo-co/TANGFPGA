# Hardware identification

| Product | Board marking or assembly | FPGA family |
| --- | --- | --- |
| TANGFPGA 9K | [Tang Nano 9K](https://wiki.sipeed.com/hardware/en/tang/Tang-Nano-9K/Nano-9K.html) | GW1NR-9C |
| TANGFPGA 20K | [Tang Nano 20K](https://wiki.sipeed.com/hardware/en/tang/tang-nano-20k/nano-20k.html) | GW2AR-18C |
| TANGFPGA 60K | [Tang Console](https://wiki.sipeed.com/tangconsole) with Mega 60K SOM | GW5AT-60B |

Read the markings on the PCB and, for Tang Console, the fitted SOM. Check the
release notes for the exact supported revisions, companion firmware, wiring and
peripherals. Tang Console can also be fitted with a 138K SOM. Select firmware
using the SOM fitted to your Console.
